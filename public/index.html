projects

    
    
Tip: in Finder, right-click the folder → hold ⌥ Option → “Copy as Pathname”, then paste. The board (.todomd/) is created if the repo doesn’t have one.

    

      …or from the terminal
      
Inside the repo, run:

      
cd /path/to/your/repo   # must be a git repo
todomd init             # scaffolds the board + registers it

      
Then refresh this page — the project appears in the switcher. todomd init is safe to re-run; on a repo that already has a board it just registers it. (If todomd isn’t found, run npm link once in the todomd folder, or use npx todomd init.)
