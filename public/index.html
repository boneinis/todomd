        welcome to todomd
        
    
        A kanban board whose database is markdown files in your repo. You drive coding agents through a verified pipeline — on the AI subscription you already pay for. Two human decisions take a card from idea to merged code.
        

    
        1 · Before you start
        
    
        Install the agent CLI you'll use and log in once — todomd drives claude (the default) or codex, so set up whichever you have (or both). Run it once to sign in. Pick the default with default_agent in .todomd/config.yml, or choose per card in its drawer. todomd just spawns the CLI you've already authenticated — it never sees your credentials.
        

    
        2 · The flow
        
    
          
      
        1. Review — new cards land here and an agent auto-triages each one (codebase insight + a proposed plan). You read it and decide.
          2. 
      
        2. Drag to Plan → an agent writes the implementation plan into the card.
          3. 
      
        3. Read the plan in Planned, then drag to Queue to approve — an agent builds it in an isolated git worktree and an independent agent verifies it.
          4. 
      
        4. It merges to Done — or stops at Needs Human if it needs a decision (open the card to answer).
          5. 
    
        
    
        Those two drags — Review→Plan and Planned→Queue — are the only steps you do by hand. Click the ? on any column header for what it does.
        

    
        3 · Add your work
        
    
        + card creates a task · ⊕ adds another repo (paste its path) · email can become cards via ✉ (IMAP). Per card you can pick the agent / model / skill in its drawer; edit a column's prompt with ✎ prompt; open it on your phone with ▦; archive or delete from the card drawer.

        Your rules
        
      
      
        Boards this agent can manage
        
      
        Routine actions allowed without asking
        
      
      
        Board selection and action permissions are enforced. Written instructions guide the agent; exceptions require your approval.
        
      
        
        
        
        
        
        
        Uses your installed Claude CLI. Choose external mode for other agents. Background checks are at least five minutes apart. Resuming a paused queue during background checks always asks.
        
      
        
      
        Connect your MCP-capable agent with todomd-mcp --board-agent and the primary token in TODOMD_MCP_TOKEN. Ask it to read board_agent_context, submit board_agent_propose actions, and save board_agent_reply updates. Your external agent must be running; To-do MD does not start or schedule it.
